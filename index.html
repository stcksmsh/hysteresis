the СИНТЕЗА visualizer

HYSTERESIS

A music visualizer that reacts to structure (builds, drops, breaks, groove) instead of the instantaneous amplitude. The image accumulates its own history: it winds up during a build, releases on the drop and hangs suspended through a break.

What's behind this text is the real thing, running in your browser. Play a track and watch it remember.

    Why "hysteresis"

    A system with hysteresis answers with its whole history, not just its current input. Most visualizers follow the level, so a single hit and the top of a long build look the same at the same loudness. A state with memory tells them apart: a short spike barely moves it, a long build winds it up, and it carries through a short break. Drag the memory to compare.

    • input level
    • instant follower

    An illustration of the principle, not the package's code. In the visualizer the memory is literal: a feedback field that keeps and decays the last few seconds of image.

    Three layers

    1

    Features

    An AudioWorklet with its own windowed FFT: perceptual bands (sub, low, mid, presence, air), spectral centroid, flatness, spectral-flux novelty, and a trigger-locked waveform ring buffer for the oscilloscope beam.

    2

    Musical state

    Beat tracking (tempo plus a phase-locked oscillator that free-runs through breaks), and build, drop and break detectors. Fused with the sidecar's structure when one is loaded; detail stays live either way.

    3

    Choreography and scene

    Spring-damper driven parameters render in WebGL2 on an OffscreenCanvas in a worker: a Julia-set substrate fed into a curl-noise feedback field (the memory), an oscilloscope beam on top, and earned symmetry that snaps full for one bar on a drop.

    Embed it

    import { init } from 'sinteza-viz'

const viz = init(canvas, {
  accent: [0.68, 0.2, 33],          // OKLCH
  tier: 'full',
  getAudioContext: () => bus?.ctx ?? null,
  getAnalyser: () => bus?.analyser ?? null,
})
// transport and the sidecar URL arrive on a window
// "player:transport" CustomEvent bus, not through this API
viz.setAccent([0.7, 0.15, 200])

    It owns nothing but the canvas: no routing, no player UI, no AudioContext of its own. That's how it runs behind kostavukicevic.com/music, and on this page.

    Where it's going

    The browser version on this page is frozen: kept running, no longer developed. Hysteresis is being rewritten natively in Rust as the brain of a physical installation: screen, DMX and LED lighting, and servo-driven choreography, all from the same offline sidecars. The current focus is a single 3D arm that dances to the song, planned automatically and executable on real servo hardware.
